# MindShift

**Learn how AI actually works — not just how to use it.**

MindShift is an AI-education platform that teaches AI fundamentals through structured courses, live tutoring, group study, and an AI tutor. Built for the FBLA Website Design competition.

---

## The Idea

Most AI learning resources are either surface-level prompt tips or graduate-level papers with nothing in between. MindShift targets the gap: a structured path through AI fundamentals built for students, with the pacing and support of an actual course rather than a blog post.

## Features

- **Eight courses** covering AI fundamentals, structured as a progressive path
- **AI tutor** for on-demand questions while working through material
- **Quizzes** to check comprehension at each stage
- **Tutoring sessions** and **group study sessions** for live, collaborative learning
- **Dashboard** as the central hub for progress and next steps
- **Achievements and leaderboard** to sustain motivation across a multi-course path
- **Resource area** for supplementary material
- **Schedule** for planning study sessions
- **Accessibility settings**, including full keyboard navigation

## Accessibility

Accessibility was a build requirement, not an afterthought. The platform includes a dedicated settings panel and full keyboard navigation, so the entire course path is usable without a mouse.

## Getting Started

```bash
# Clone the repo
git clone https://github.com/samjm2/mindshift.git
cd mindshift

# Install dependencies
npm install

# Run locally
npm run dev
```

> Setup steps assume a standard Node/npm project — adjust to match the actual config in this repo.
